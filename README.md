# Portfólio Pessoal | Ana Paula Feitoza 💻

Este é o meu portfólio pessoal desenvolvido como parte da atividade prática da disciplina **Fundamentos da Programação Web**. O objetivo principal foi aplicar os conhecimentos em **HTML5**, **CSS3** e **JavaScript puro**, desenvolvendo uma página responsiva, acessível e com foco em design limpo e funcional.

## 📝 Sobre o Projeto

O portfólio foi pensado como um currículo online moderno e responsivo, onde apresento minha trajetória, formação, projetos e formas de contato. O site é uma SPA (Single Page Application), com navegação por âncoras e layout adaptado para dispositivos móveis e desktops.

### 🔗 Acesse o site publicado:
👉 [Ver site online](https://apfeitoza.github.io/projeto-portifolio/)

---

## 📌 Funcionalidades

- Alternância de tema (claro/escuro)
- Navegação intuitiva com menu fixo
- Layout responsivo para dispositivos móveis
- Seções:
  - **Home** – Apresentação pessoal
  - **Sobre Mim** – Minha história e motivações
  - **Trajetória** – Formação acadêmica e experiência profissional
  - **Projetos** – Exibição de projetos com links de prévia e repositório
  - **Contato** – Formulário visual com nome, e-mail e mensagem

---

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3 (sem frameworks, apenas CSS puro)
- JavaScript puro (para alternância de tema)
- Git e GitHub Pages (hospedagem gratuita)
- Contribuição ao Projeto de portifóli da Dio
